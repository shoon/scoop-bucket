# Scoop bucket for fv-ssh-unlock

This is the official project-owned Scoop bucket for
[`fv-ssh-unlock`](https://github.com/shoon/fv-ssh-unlock).

Install the current prerelease on Windows:

```powershell
scoop bucket add shoon https://github.com/shoon/scoop-bucket
scoop install shoon/fv-ssh-unlock
```

The manifest selects the AMD64 or ARM64 release archive and verifies its
SHA-256 checksum. See the
[project documentation](https://github.com/shoon/fv-ssh-unlock/blob/main/docs/getting-started.md)
for FileVault setup, credential-storage guidance, and release verification.
